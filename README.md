# EcoSuit MK.I — Design Brief
**Hemp-composite-core ceramic plate armor · Internal exoskeleton · Iron Man design language**

---

## One-line concept
Space Shuttle Atlantis thermal protection condensed into a wearable vehicle: ceramic heat-shield plates with a hemp-composite core, hung on an internal powered exoskeleton, styled as segmented heroic armor rather than a tiled mosaic.

---

## Design language (Iron Man pass)
- **Silhouette:** Athletic, compact, armored. Not a balloon suit. Not a low-poly statue.
- **Plates:** Larger overlapping segments (chest plastron, pauldrons, vambraces, cuisses, greaves). Small-triangle facet pattern lives *on* each segment as surface language, not as thousands of separate tiles.
- **Helmet:** Hard ceramic/composite faceplate. Narrow horizontal visor slit with gold-amber glow. No fishbowl.
- **Joints:** Visible dark-metal actuators at shoulders, elbows, hips, knees, ankles. The machine is allowed to show.
- **Chest:** Integrated life-support / power module (not an arc reactor copy). Visual focus without Marvel IP.
- **Palette:** Matte black HRSI ceramic · bone / off-white LRSI ceramic · dark exo metal · single gold-amber visor line. Hemp-fiber texture only at seams and cutaways.
- **Motion:** Plates slide, nest, and lock. Suit reads as something that can open and close.

---

## Architecture

### 1. Outer skin — ceramic plate segments
- High-purity silica / alumina-silica ceramic faces.
- Black-coated high-heat zones (re-entry, sun-facing, abrasion).
- White / uncoated lower-heat zones (thermal control on orbit).
- Segment edges faceted in the original sketch’s triangle language.
- Gaps use flexible fillers or overlapping scale geometry so the armor can articulate.

### 2. Core — hemp composite sandwich
- Woven hemp bast (or oriented hurd) + high-temp matrix (phenolic / ceramic-compatible / encapsulated bio-resin).
- Replaces the Shuttle Nomex strain-isolation pad **and** adds toughness.
- Jobs: isolate ceramic from frame strain, damp vibration/impact, cut mass, keep the system growable and repairable.
- Hemp shows only at plate edges, service hatches, and cutaways — not as a rustic outer finish.

### 3. Inner mount
- Thin composite or metallic backing on each segment.
- Bolts / bonds to the internal frame so the ceramic never takes primary structural load.

### 4. Internal exoskeleton (the “airframe”)
- Wearable space-frame: spine, rib analog, pelvic yoke, limb longerons.
- Hybrid hemp-carbon or titanium / S-glass struts and nodes.
- Passive structure + optional powered assist against suit pressure, gravity, and tool loads.
- Joint recipe from hard-suit lineage (Mark III / xEMU): bearings + rolling convolutes + constant-volume soft sections at elbow, knee, waist.
- Rear-entry hatch integrates with the dorsal lattice the way payload-bay doors sat on the Shuttle mid-fuselage.

**Load path:** Body → exo frame → hemp core → ceramic face.  
Ceramic is a passenger. Frame is the vehicle.

## Operating concept
- Hybrid hard/soft pressure garment. Target high operating pressure (Mark III-class, ~8 psi) for reduced pre-breathe, **or** MCP + gas hybrid so plates are not the sole pressure vessel.
- Frame indexes the body, carries armor, and can take actuator load.
- Donning: rear hatch; segments can unlock / slide for access and maintenance.
- Mobility tasks: kneel, climb, tool work — rigid chassis + articulated extremities, not a pressurized fabric bag.

---

## Why hemp stays in the stack
- Low density + damping vs. pure ceramic or all-metal hard shell.
- Impact energy absorption (ceramics crack; the core should not).
- Renewable feedstock, lower embodied energy than aerospace carbon/aramid at this layer.
- Hybrid-ready (hemp core + ceramic face, or hemp/carbon skins).

**Open problems (do not hand-wave):** outgassing, moisture, flammability, atomic oxygen, vacuum/radiation stability, ceramic–hemp interface, NASA-STD-6001 / 6016 class testing. Solve with matrix, coatings, encapsulation — same class of problem as tile densification and waterproofing.

## Visual spec (for artists / CAD)
- Hero pose: three-quarter standing, weight on one leg, shoulders set.
- Helmet: smooth rounded faceplate, slit visor only, gold-amber glow, no traditional neck ring bubble.
- Armor: overlapping black/bone plates, triangle etch on each plate, dark metal showing at every major joint.
- Cutaway (optional): hemp fiber core + lattice struts on one torso/arm only.
- Do **not** use red-and-gold Marvel livery. Do **not** use a spherical glass helmet. Do **not** return to tiny all-over mosaic.
